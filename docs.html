Documentation

SKONGA AI app docs

How to install, set up, study, unlock Pro, and keep the app updated. This is product documentation — for company identity see About; for short answers see FAQ.

1. Install (Android APK)

  1. Open the official download page: skonga-web.vercel.app/#download or GitHub Releases.
  2. Download the latest signed file (name like SKONGA-AI-release.apk). Prefer release over old debug builds.
  3. On your phone, open the downloaded file.
  4. If Android asks, allow install from this source (browser or file manager).
  5. Confirm install. Open SKONGA AI.
Play Protect

Apps outside Google Play may show a one-time warning. Use only the official SKONGA release link. Choose install if you trust that source.

2. First run

  • On first launch you may be asked for Form (1–6).
  • For Form 5 or 6, you can optionally pick your subject combination (tahasusi).
  • You can skip combination; you can change profile later in settings where available.
  • Grant camera permission only if you use scan features.

3. Chat & study features

  • AI Chat — type a question; get explanations aimed at secondary level.
  • Scan & Solve — capture a written question when the feature is available in your build.
  • Use clear questions (topic + what you don’t understand) for better answers.
  • Free tier has soft limits; when you hit the limit, the app guides you to Pro.

4. Form & Combination

Personalization helps the assistant stay on relevant subjects.

  • Form 1–4 — form level is enough for general secondary help.
  • Form 5–6 — choose combination (e.g. PCM, HGE) so suggestions match your tahasusi.
  • Combination is optional but recommended for A-level students.

5. Pro & mobile money

  • Open the in-app Pro / payment sheet and pick a plan (day, week, month, or year — as shown in the app).
  • Enter phone in format 2556XXXXXXXX (or as the app instructs).
  • Confirm; complete the USSD / mobile-money prompt on your phone.
  • After payment, Pro should show as active (e.g. green “Active until…”). If the UI does not unlock immediately, use “I paid — unlock” / wait for sync, or reopen the app online.
Payments

Only pay through the official SKONGA AI in-app flow. Keep your payment reference (TID) if you need support.

6. Updates

  • When online, the app can check a remote version.json and prompt you to download a new APK.
  • You can always get the latest file from the website download section.
  • Install the new APK over the old one (same app id) to keep data where possible.

7. Try in browser

Some study flows are available on the web: app.skonga.ai. Full mobile features (APK, system install, some device APIs) work best on the Android app.

8. Troubleshooting

  • Install blocked — enable install from your browser/file manager; use the signed release APK.
  • Play Protect warning — confirm the download URL is official, then install.
  • Paid but not Pro — stay online, reopen app, use unlock/sync; contact support with TID if needed.
  • No network — chat needs internet; some profile data may still be local.
  • Wrong suggestions — set Form and Combination correctly.
